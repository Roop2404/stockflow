# StockFlow

Phase 1 foundation: FastAPI, SQLAlchemy, Alembic, PostgreSQL 17, and Next.js.

Start DB: `docker compose -f infrastructure/docker-compose.yml up -d db`.
Backend (Python 3.13): in `backend`, install `requirements.txt`, copy `.env.example` to `.env`, run `alembic upgrade head`, then `uvicorn app.main:app --reload`. Docs at /docs.
Frontend: in `frontend`, run `npm install && npm run dev`; open localhost:3000.
The reviewed initial migration creates organizations, users, products, organization_settings. Future autogenerated migrations should be reviewed. No create_all, authentication, or inventory workflows are included.
